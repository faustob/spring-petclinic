- qr-endpoint-env-driven (`src/main/resources/otel.env.example`): Hardcoded OTLP endpoint "http://localhost:4317" — wrong in every real deployment.
- qr-not-a-noop (`src/main/java/org/springframework/samples/petclinic/PetClinicApplication.java`): AutoConfiguredOpenTelemetrySdk.builder() requires the otel-sdk-extension-autoconfigure module and by default will NOT export metrics/traces unless OTEL_METRICS_EXPORTER/OTEL_TRACES_EXPORTER (or default otlp) and an endpoint are configured; more critically, the recorded histograms only emit if a MetricReader/PeriodicMetricReader is wired. With autoconfigure and the otlp exporter on the classpath this works, but the code swallows the IllegalStateException on a duplicate-global registration rather than a broader failure — that part is acceptable. The real risk is fine as configured.
- qr-preserves-behavior (`src/main/resources/static/js/web-vitals-reporter.js`): The injected module script references window.__petclinicReportVital inside the module source, but window.__petclinicReportVital is assigned AFTER the script element's textContent is set; module scripts execute asynchronously so the assignment happens before execution, making this a race that usually works but is order-fragile.
- qr-not-a-noop (`src/main/resources/static/js/web-vitals-reporter.js`): The reporter assigns window.__petclinicReportVital AFTER appending the module script that references it; module scripts execute asynchronously but the callback identity is captured lazily, yet there is no route/page that ever includes this web-vitals-reporter.js file — no Thymeleaf template or layout is edited to add a <script src>. The client instrumentation is never loaded, so /api/vitals is never called and the LCP/INP histograms never receive data.
- general (`src/main/resources/static/js/web-vitals-reporter.js`): window.__petclinicReportVital is set after document.head.appendChild(script); if the module fetch/import resolves before the property assignment runs, onLCP/onINP register with an undefined callback. Assign the global before appending the script.
- general (`src/main/java/org/springframework/samples/petclinic/PetClinicApplication.java`): The imported GlobalOpenTelemetry symbol is unused in PetClinicApplication.java.
**Outstanding (3):**
